# ⚖️ 刑法 3-Column 知識庫筆記 (Criminal Law Notes)

> 基於現代 **Note 3 Column** 規範打造的高美學、互動式刑法總論學習知識庫。以直觀「壞人做壞事」的生活常理為出發點，完整解析三階層論罪體系、雙重推定與反證邏輯（目前完整收錄導論第一章教材第 1-1 ～ 1-5 頁，涵蓋案例 1-1 ～ 1-8 與最新 2026 法規查核）。

---

## 🌟 核心特色

1. **三欄式現代知識庫架構 (3-Column Layout)**：
   - **左側邊欄 (Sidebar)**：篇章分類導航樹、章節即時切換、手機抽屜式收合。
   - **中央主文 (Main Reader)**：完整收錄課本第 1-1 ～ 1-5 頁原文與論罪推演、精緻還原書中架構圖解、生活化巴掌比喻認知流程、經典案例卡片與 2026 現行法規連動查核。
   - **右側目錄 (Table of Contents)**：即時滾動監聽定位 (Scrollspy)、八大小節無縫切換、平滑回頂。
2. **⚡ 論罪推定雙重架構還原**：
   - **第一重推定**：壞事推定壞人（不法推定罪責）➔ 阻卻罪責事由反證推翻（期待可能性核心、法定 vs 超法定樹狀展開）。
   - **第二重推定**：法益侵害推定無正當理由（構成要件該當推定違法性）➔ 阻卻違法事由反證推翻（依法令、依命令之行為）。
3. **經典實戰教案與金句演進收錄**：
   - ⚖️ **阻卻罪責抗辯（案例 1-1 ～ 1-6）**：「因而雖做壞事，但卻不是壞人。」（不知法律、幼年、精神障礙、瘖啞、過當防衛/避難、幼兒墜床火災期待可能性）。
   - ⚖️ **阻卻違法抗辯（案例 1-7 ～ 1-8）**：「縱使造成法益侵害，但因有正當理由而並非壞事。」（優生保健醫師合法墮胎、服從合法上級公務員命令）。
4. **極致閱讀與研讀體驗**：
   - 深色曜石黑（Obsidian `#0B0F17`）與俐落淺色（Clean Slate）一鍵切換。
   - 零依賴單檔 HTML 架構，任何電腦雙擊即可秒開瀏覽。

## 📤 一鍵推送到 GitHub

專案目錄內已內建高相容性的自動化腳本：

1. 雙擊執行 `push_to_github.bat`。
2. 腳本會自動檢查 Git 狀態、暫存變更並引導您輸入 Commit 訊息。
3. 若尚未關聯 GitHub 遠端，腳本會貼心提示您輸入倉庫 URL。
4. 自動推送至 `origin/main` 分支。

### 🌐 啟用 GitHub Pages 線上公開筆記
在您的 GitHub 倉庫頁面：
1. 點擊頂部 **Settings** ➔ 側邊欄點選 **Pages**。
2. 在 **Branch** 選擇 `main` 分支與 `/(root)` 目錄。
3. 點擊 **Save**，稍等 1~2 分鐘即可獲得專屬公開線上網址！
