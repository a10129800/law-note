# 🛠️ 刑法總則知識庫・開發筆記 (Dev Notes)

> 本文件記錄《刑法總則【圖說系列】》多欄位漸進式筆記的架構決策、功能迭代歷程與踩坑經驗。

---

## 🎯 專案目標與技術決策

- **核心訴求**：將繁雜的刑法教科書與 2026 最新法規，重構成具備「直觀圖解＋三階層審查＋即時法條對照」的現代化多欄位閱讀器。
- **技術選型**：
  - **純原生（Vanilla HTML / CSS / JS）**：零框架依賴、離線雙擊秒開。
  - **三欄佈局（CSS Grid）**：左側目錄樹、中欄漸進主文、右側動態吸頂 TOC。
  - **母本雙軌安全機制**：以 `visual.html` 為純 UTF-8 乾淨母本，發布時單向同步至 `index.html`，杜絕編碼損壞。

---

## 📅 迭代歷程與里程碑 (Milestones)

### 📌 Milestone 1：教材知識庫體系建置 (v1.0)
- **書籍主頁**：CSS 3D 透視擬真書封（`perspective: 1200px`）、中繼資料看板、圖解藝廊。
- **第零篇導讀**：收錄四大運作支柱原文。
- **第一章《犯罪的概念》**：全 8 節、案例 1-1 ～ 1-17、不法推定罪責模型、概念焦點框（Sky Blue 色塊）。
- **第二章《刑法的論罪結構》**：全 4 節、案例 2-1 ～ 2-4、二階 vs 三階對抗矩陣、四大拼圖模型。
- **2026 現行法規查核**：標註全法條修法動態與 113年憲判字第8號裁判拘束力。

### 📌 Milestone 2：全域導航與檢索升級 (v1.5)
- **`Ctrl+K` 全域智慧搜尋**：四象限分類（全部/案例/法條/學說）、鍵盤上下鍵巡覽。
- **搜尋脈衝導引**：跳轉後目標卡片自動居中，並施加 2.5 秒脈衝光暈（`.search-target-highlight`）。
- **章節雙向分頁導航**：文末配置「← 上一章／下一章 →」兩欄卡片，引導體系閱讀。
- **頂部微流光進度條**：2.5px 雙色漸層即時反映滾動百分比。

### 📌 Milestone 3：學習賦能三要素 (v2.0)
- **法條原地懸浮預覽**：收錄 19 條重要條文與裁判，原地預覽法條全文與國考審查要點。
- **環形滾動進度按鈕 (FAB)**：右下角 SVG 動態環形進度圈（周長 `125.66px`），>300px 浮現，懸停顯示數字百分比。
- **案例爭點一鍵導出**：卡片標頭配置「📋 複製筆記」，格式化為 Anki / Notion / Obsidian 雙鏈 Markdown，附帶微 Toast 提示。

### 📌 Milestone 4：UX 痛點重構與防截斷修復 (v2.1)
*針對使用者測試回饋進行關鍵調優：*
1. **底線雜訊過多** ➔ 廢除正文貪婪掃描，僅精準綁定案例徽章與法規連結，還原純淨閱讀。
2. **桌面防誤觸** ➔ 懸停加入 260ms 防誤觸延遲，滑鼠劃過不再閃爍。
3. **行動端遮擋** ➔ 手機端全面改為自底端滑出的**抽屜面板 (Bottom Sheet)**，配置毛玻璃遮罩與 `✕` 關閉按鈕。
4. **長標題被截斷 (Truncation Bug)** ➔ 電腦版寬度擴增為 27rem（432px），標頭重構為**雙層結構**（第 1 層徽章+關閉鈕、第 2 層整行標題 `break-words`，徹底移除 `truncate`）。

## ⚠️ 架構防坑筆記 (Gotchas)

| 地雷問題 | 根本原因 | 解決方案 |
| :--- | :--- | :--- |
| **右側目錄掉落至頁尾** | 內文小節遺留多餘未閉合的 `</div>`，導致 `<main>` 提前閉合。 | 確保 `.app-layout-container` 嚴格維持 3 個一級子節點。 |
| **章節切換時畫面全黑** | 小節少寫 `</section>`，使後續視圖被誤包覆於父層遭 `display: none`。 | 所有 `#viewXXX` 必須為平級兄弟節點，`<section>` 1:1 精確配對。 |
| **標題尾端被「...」吃掉** | 在單一行內塞入徽章、關閉鈕與標題，並套用 `truncate`。 | 拆為雙層標頭，標題獨立成行使用 `break-words`。 |
| **Windows 繁中亂碼** | CP950 / ANSI 判定衝突使 UTF-8 中文碎裂為菱形問號。 | 保持 UTF-8 無 BOM，自動化腳本鎖定由乾淨母本 `visual.html` 覆蓋目標檔。 |
